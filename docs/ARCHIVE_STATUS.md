# Archive Status

This repository is an archived historical snapshot.

It is preserved for:
- reproducibility,
- audit trail continuity,
- reference by future AxonOS work,
- historical traceability of the consent-state-machine line.

This repository is not the active AxonOS consent implementation.

Active development should happen in the current AxonOS repositories under:

- https://github.com/AxonOS-org
- https://github.com/AxonOS-BCI

## CI Scope

The CI workflow in this repository is an archival validation workflow.

It verifies:
- repository surface,
- README archive notice,
- license/documentation presence,
- no obvious secret leaks,
- no generated artifacts,
- optional Rust metadata,
- optional Rust tests,
- historical snapshot sanity.

It is not a production-release certification workflow.
